# Dextereous-Hand-RH56DFX-UDI
In this repository, you'll find all the documentation related to the development of a project whose main objective the teleoperation of the Dextereous Hand RH56DFX using an Intel RealSense depth camera.
# **Inspire Robot RH56DFTP Library**
The base library for the devolpment of the SDK in this project was recovered from: https://pypi.org/project/inspire-rh56dftp/
Run this in your terminal to get it downloaded `pip install inspire_rh56dftp[viz]`
